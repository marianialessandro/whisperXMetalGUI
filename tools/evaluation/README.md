# Released AMI voice evaluation

These CLI tools add actual diarization-turn evidence to the released-dataset benchmark. They do not change the app, original worker, production algorithm or the existing baseline CLI defaults.

`voice_adapter.py --speaker-turns NEW_JSON` forwards worker/source/spans/seed arguments to the existing adapter. Its process-local wrapper retains the DataFrame returned by the diarization call before word-speaker assignment, including simultaneous speaker turns. It preserves the return object and restores every wrapper after success or failure. It refuses empty/invalid turns and output overwrite. The retained turns come from the instrumented process; raw original-turn parity is not measured. Original/adapter result and export parity is independently required by the paired runner.

`voice_pair.py` runs one source-verified released AMI case with voices enabled, using the private Keychain bridge only after audio, license, reference, model and cache gates. Required options are `--evidence-root`, `--snapshot`, `--catalog`, `--licenses`, `--case-id`, `--source-root`, `--runtime`, `--reference-root`, `--model-specs` and `--bridge`. Optional `--quality`, `--speaker-count` and `--timeout` preserve automatic speaker estimation when no exact count is supplied. Both workers run offline in separate cold processes with seed 1729. Credentials remain in memory/private child requests and never enter argv, environment, manifests or reports. Warnings and semantic mismatches fail the pair. DER/JER and speaker-count error use actual turns; word-speaker agreement reuses the recording's Hungarian speaker mapping. Collar is zero, overlap is included and UEM uses the full-recording dataset convention. The source-supplied annotation method remains explicit; no local reviews are manufactured.

`voice_baseline.py --evidence-root ROOT --snapshot NEW_NAME plan` takes catalog/licenses/source/runtime/reference/model arguments, optional `--profiles Rapida Bilanciata Massima`, and optional `--speaker-mode auto|exact`. It fixes disjoint AMI recording/session/speaker splits and three replicas per recording before any voice score. Exact counts, when selected, come from the dataset reference; automatic estimation remains the default. `run` takes source/runtime/reference/model/bridge arguments, plus optional timeout. Completed receipts are hash-verified and skipped during resume; incomplete attempts remain preserved and a new exclusive attempt is created. The voice tools have a separate harness identity from the text benchmark.

`calibrate` averages replicas within each recording and bootstraps calibration recording means with seed 17, 2000 resamples and confidence 0.95. Bounds and repeat variability deltas never use heldout scores. Heldout results remain diagnostic even if outside a bound. `seal` requires all planned measurements and recomputes their scores from retained outputs and released references. It returns an external SHA-256; `verify --sha256 CHECKSUM` rechecks artifacts and calibration. Sealing covers the selected released voice benchmark and archived execution evidence, not independently adjudicated word timing, population accuracy, Italian meeting coverage or complete operator GPU placement.
